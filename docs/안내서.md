# 우리 반 교실 보드 안내서

## 1. 들어가는 방법
1. https://gonigoun.github.io/classboard/ 를 열고 **시작하기**를 눌러요.
2. 이미 로그인돼 있으면 역할에 맞는 화면으로 바로 가요.
   - 허용된 선생님 → 선생님 보드
   - 학급에 들어온 학생 → 학생 화면
3. 로그인돼 있지 않으면 역할을 골라요.
   - **선생님**: Google로 로그인 → 허용된 계정이면 보드, 처음이면 **권한 요청** 화면이 나와요.
   - **학생**: Google로 로그인 → 학급 코드와 **선생님 명단에 있는 이름**을 넣으면 바로 들어가요. 번호는 명단 번호로 저절로 정해져요.
   - **게스트**: 로그인 없이 모든 기능을 둘러봐요. 바꾼 내용은 저장되지 않아요.

## 2. 선생님 권한 승인 (관리자: gonigoun@gmail.com)
- 보드 오른쪽 위 아바타 → **설정 → 허용할 선생님** 탭에서 요청을 **승인/거절**해요.
- 이메일을 직접 추가하거나 허용을 취소할 수도 있어요.

## 3. 학생 폰 연결
1. 위젯 바의 **학생 입장**을 열면 학급 코드·주소·QR 코드가 보여요.
2. 학생은 폰에서 주소(또는 QR)를 열고 Google로 로그인한 뒤 **이름**을 넣어요. 설정 → 학생 명단에 적은 이름과 같아야 들어올 수 있어요(띄어쓰기는 상관없음).
   - 명단은 `3 박도윤`처럼 **번호 이름**으로 적어요. 비는 번호는 빼면 돼요.
   - 같은 이름이 두 명이면 `김민준A`, `김민준B`처럼 다르게 적고 학생에게 알려 주세요.
   - 학급 코드에는 이름 대신 알아볼 수 없는 지문만 올라가요. 명단을 바꾸면 보드를 연 화면에서 바로 반영돼요.
3. 누가 들어왔는지는 같은 창에서 **이메일**로 확인해요.
   - 명단 이름과 다르면 주황색으로 표시돼요.
   - 폰을 바꾼 학생은 **자리 비우기**를 누르면 다시 들어올 수 있어요.
4. **학생 입장 열기**를 끄면 새로 들어올 수 없어요. 이미 들어온 학생은 그대로예요.
5. 한 번호에는 한 계정만 들어올 수 있어요.

## 4. 과제
- 설정 → 시간표·과제에서 교시마다 **과제 방식**을 골라요.
  - **순서대로(정류장)**: 앞 과제를 해야 다음으로 넘어가요. 보드에서 이름표를 누르면 다음, 길게 누르면 뒤로 가요.
  - **골라서 하기**: 여러 과제 중 **완료 기준 n개**만 하면 완료예요. 보드에서는 학생 × 과제 표의 칸을 눌러요.
- 학생이 폰에서 체크하면 보드에 바로 반영되고, 보드에서 바꾸면 학생 폰에도 바로 반영돼요.
- 과제 현황 제목줄의 **크게 보기**로 전체 화면에 띄울 수 있어요. 과제 이름은 크게, 학생 이름은 작게 여러 줄로 나와요.
- **아침 시간**: 1교시 전 칸이에요(기본 08:40~09:00). 수업처럼 과제 현황과 판서를 쓸 수 있고, 시작할 때 종은 울리지 않아요.
- **판서**는 수업 중뿐 아니라 아침 시간·쉬는 시간·점심시간·곧 시작할 때도 쓸 수 있어요. 수업이 아닐 때는 판서 오른쪽 위에 **다음 수업까지 남은 시간**이 보여요. 설정에서 시간·과제를 바꾸거나 지울 수 있고, 지운 뒤에는 **아침 시간 추가**로 다시 넣어요.
- 시간표의 시작·끝 시간은 **5분 단위**로 골라요.

## 5. 메시지
- 학생은 폰 아래의 **선생님께 메시지**로 보내요(300자까지).
- 선생님 보드에는 알림과 함께 위젯 바 **메시지**에 숫자가 떠요. 열어서 답장할 수 있어요.
- 선생님이 **먼저** 보낼 수도 있어요: 메시지 창 위쪽에서 받는 학생(또는 **모두에게**)을 고르고 **쓰기**. 폰으로 들어온 학생에게만 보낼 수 있어요.

## 5-1. 휴대폰으로 함께 쓰기 (순회 지도)
- 노트북(TV)과 휴대폰에서 **같은 선생님 계정**으로 로그인하면 두 화면이 연동돼요.
  - 바로 맞춰지는 것: 과제 체크, 메시지, 신호등, 시간표·명단 설정, **집중 종**(폰에서 누르면 TV에서 울림), **타이머**(폰에서 시작·더하기·멈춤 → TV도 같이), **판서 선과 글자**
  - 폰에서 판서를 켜면 TV는 판서를 크게 띄워요. 폰에서 **판서 닫기**를 누르면 TV도 닫혀요.
  - 판서 그림(사진)은 그 화면에만 있어요. 판서 선·글자는 연동을 위해 그날만 잠깐 저장되고 다음 날 지워져요.
- 폰을 **가로로** 돌리면 TV 판서와 거의 같은 모양으로 넓게 쓸 수 있어요. 세로일 때는 빨간 점선 아래가 TV에 안 보이는 부분이에요.
- 폰 화면: 위젯 바는 자주 쓰는 4개(이름 뽑기·신호등·타이머·메시지)와 **더보기**, 판서는 화면 가득, 도구는 옆으로 밀어서 골라요.

## 6. 타이머
- 위젯 바 **타이머**: 시·분·초를 정하거나 30초·1분·3분·5분·10분 버튼을 눌러요.
- 모양: 모래시계 / 부채꼴 / 숫자만
- **−5분 · −1분 · −30초 · +30초 · +1분 · +5분** 버튼은 언제나 보여요. 시작 전에는 맞춰 둔 시간을, 시작한 뒤에는 남은 시간을 바로 더하거나 빼요. 모래시계·부채꼴 양도 따라 바뀌어요. 시간이 끝난 뒤 더하기를 누르면 그 시간만큼 다시 시작해요.
- 판서를 **크게 보기**로 띄웠을 때는 판서 도구 막대 오른쪽의 타이머·이름 뽑기·소음·신호등 버튼으로 위젯을 판서 위에 열어요.
- 끝날 때 소리는 집중 종 5가지 중에서 골라요. 창은 끌어서 옮기고 모서리로 크기를 바꿔요.

## 7. 저장되는 것
| 저장 위치 | 내용 |
|---|---|
| Firebase 서울 서버 (로그인한 선생님) | 설정(요일별 시간표·과제·명단·소리·배경·위젯 위치) |
| Firebase 서울 서버 (로그인한 선생님) | 날짜별 시간표와 학생별 과제 체크 (한 학기 보관) |
| Firebase 서울 서버 (로그인한 선생님) | 학생 자리(번호·이름·이메일), 메시지 |
| 저장 안 함 | 판서, 게스트 모드에서 바꾼 내용 |

## 8. 새 버전을 반영할 때 (중요)
코드를 반영할 때 보안 규칙이 바뀌었다면, Firebase 콘솔 → Firestore → **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 **게시**해야 해요.

- 종소리·효과음: 브라우저에서 직접 합성한 소리 (음원 파일 없음)
