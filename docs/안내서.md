# 우리 반 교실 보드 안내서

## 1. 들어가는 방법
1. https://gonigoun.github.io/classboard/ 를 열고 **시작하기**를 눌러요.
2. 이미 로그인돼 있으면 역할에 맞는 화면으로 바로 가요.
   - 허용된 선생님 → 선생님 보드
   - 학급에 들어온 학생 → 학생 화면
3. 로그인돼 있지 않으면 역할을 골라요.
   - **선생님**: Google로 로그인 → 허용된 계정이면 보드, 처음이면 **권한 요청** 화면이 나와요.
   - **학생**: Google로 로그인 → 학급 코드·번호·이름을 넣으면 바로 들어가요(자동 승인).
   - **게스트**: 로그인 없이 모든 기능을 둘러봐요. 바꾼 내용은 저장되지 않아요.

## 2. 선생님 권한 승인 (관리자: gonigoun@gmail.com)
- 보드 오른쪽 위 아바타 → **설정 → 허용할 선생님** 탭에서 요청을 **승인/거절**해요.
- 이메일을 직접 추가하거나 허용을 취소할 수도 있어요.

## 3. 학생 폰 연결
1. 위젯 바의 **학생 입장**을 열면 학급 코드·주소·QR 코드가 보여요.
2. 학생은 폰에서 주소(또는 QR)를 열고 Google로 로그인한 뒤 번호·이름을 넣어요.
3. 누가 들어왔는지는 같은 창에서 **이메일**로 확인해요.
   - 명단 이름과 다르면 주황색으로 표시돼요.
   - 폰을 바꾼 학생은 **자리 비우기**를 누르면 다시 들어올 수 있어요.
4. **학생 입장 열기**를 끄면 새로 들어올 수 없어요. 이미 들어온 학생은 그대로예요.
5. 한 번호에는 한 계정만 들어올 수 있어요.

## 4. 과제
- 설정 → 시간표·과제에서 교시마다 **과제 방식**을 골라요.
  - **순서대로(정류장)**: 앞 과제를 해야 다음으로 넘어가요. 보드에서 이름표를 누르면 다음, 길게 누르면 뒤로 가요.
  - **골라서 하기**: 여러 과제 중 **완료 기준 n개**만 하면 완료예요. 보드에서는 학생 × 과제 표의 칸을 눌러요.
- 학생이 폰에서 체크하면 보드에 바로 반영되고, 보드에서 바꾸면 학생 폰에도 바로 반영돼요.
- 과제 현황 제목줄의 **크게 보기**로 전체 화면에 띄울 수 있어요.

## 5. 메시지
- 학생은 폰 아래의 **선생님께 메시지**로 보내요(300자까지).
- 선생님 보드에는 알림과 함께 위젯 바 **메시지**에 숫자가 떠요. 열어서 답장할 수 있어요.

## 6. 타이머
- 위젯 바 **타이머**: 시·분·초를 정하거나 30초·1분·3분·5분·10분 버튼을 눌러요.
- 모양: 모래시계 / 부채꼴 / 숫자만
- 끝날 때 소리는 집중 종 5가지 중에서 골라요. 창은 끌어서 옮기고 모서리로 크기를 바꿔요.

## 7. 저장되는 것
| 저장 위치 | 내용 |
|---|---|
| Firebase 서울 서버 (로그인한 선생님) | 설정(요일별 시간표·과제·명단·소리·배경·위젯 위치) |
| Firebase 서울 서버 (로그인한 선생님) | 날짜별 시간표와 학생별 과제 체크 (한 학기 보관) |
| Firebase 서울 서버 (로그인한 선생님) | 학생 자리(번호·이름·이메일), 메시지 |
| 저장 안 함 | 판서, 게스트 모드에서 바꾼 내용 |

## 8. 새 버전을 반영할 때 (중요)
코드를 반영할 때 보안 규칙이 바뀌었다면, Firebase 콘솔 → Firestore → **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 **게시**해야 해요.

- 종소리·효과음: 브라우저에서 직접 합성한 소리 (음원 파일 없음)
