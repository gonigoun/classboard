따라 하기 안내

가. GitHub에 이 페이지 올리기
  1. github.com에서 가입해요 (이메일 인증 포함). 아이디는 주소에 들어가요. 예: goun → goun.github.io
  2. 오른쪽 위 + → New repository → 이름 classboard → Public 선택 → Add a README file 체크 → Create repository
  3. Add file → Upload files → 이 파일 test.html을 끌어다 놓고 → 아래 Commit changes
  4. Settings → Pages → Source는 Deploy from a branch, Branch는 main / (root) → Save
  5. 1~2분 뒤 https://아이디.github.io/classboard/test.html 을 학교 노트북에서 열어요
나. Firebase 만들기 (Google 계정으로)
  1. console.firebase.google.com → 프로젝트 만들기 → 이름 classboard → Google 애널리틱스는 꺼도 돼요
  2. 왼쪽 빌드 → Authentication → 시작하기 → 로그인 방법에서 Google 사용 설정 → 지원 이메일 선택 → 저장
  3. Authentication의 설정 → 승인된 도메인 → 도메인 추가 → 아이디.github.io 입력
  4. 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3 (서울) → 프로덕션 모드로 시작
    '테스트 모드'는 30일 뒤에 막히니 고르지 마세요. 위치는 나중에 바꿀 수 없어요.
  5. Firestore의 규칙 탭에 아래 내용을 통째로 붙여 넣고 게시 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /boards/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
  6. 왼쪽 위 톱니바퀴 → 프로젝트 설정 → 내 앱에서 웹 아이콘 </> → 앱 닉네임 입력 → 등록 → 나오는 firebaseConfig를 복사해서 위 2번 칸에 붙여 넣기

Firebase 화면의 메뉴 이름은 조금씩 바뀔 수 있어요. 비슷한 이름을 찾으면 돼요.
